# UberClone — Versión Conductor 🚗📱

Aplicación móvil multiplataforma inspirada en Uber (versión para conductores) desarrollada con React Native y Expo. Permite la recepción de solicitudes en tiempo real, seguimiento por GPS, cálculo de tarifas y cobro de viajes.

---

## 🚀 Requisitos e Instalación

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/juandeyan-dev/uber-clone-driver.git](https://github.com/juandeyan-dev/uber-clone-driver.git)
   cd uber-clone-driver

2. Instalar dependencias:

Bash
npm install

3. Iniciar el proyecto con Expo:

npx expo start

🔑 Variables de Entorno
Antes de ejecutar la aplicación, crea un archivo .env en la raíz del proyecto tomando como base el archivo .env.example:

cp .env.example .env

Configura las llaves necesarias en el archivo .env:

GOOGLE_MAPS_API_KEY: Clave de API para Maps, Directions y Distance Matrix.

MERCADOPAGO_PUBLIC_KEY: Clave pública de prueba para Mercado Pago.
